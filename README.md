<h1 align="center">🌙 Nyx</h1>

<p align="center">
<strong>Bot multifuncional para Discord</strong>
</p>

<p align="center">
Nyx é um bot desenvolvido para servidores do Discord com o objetivo de adicionar 
funcionalidades úteis, automação e interação entre os membros da comunidade.
</p>

<p align="center">
O projeto foi criado para aprender mais sobre desenvolvimento de bots, 
automação de servidores e integração com APIs.
</p>

<hr>

<h2>🚀 Funcionalidades</h2>

<ul>
<li>⚙️ Comandos de utilidade</li>
<li>🎮 Comandos interativos para usuários</li>
<li>🛠 Ferramentas de administração</li>
<li>📊 Automação para servidores</li>
<li>💬 Sistema de interação com membros</li>
</ul>

<hr>

<h2>🛠 Tecnologias Utilizadas</h2>

<ul>
<li><strong>Python</strong></li>
<li><strong>discord.py</strong></li>
<li><strong>APIs externas</strong></li>
</ul>

<p>
A biblioteca <strong>discord.py</strong> permite interagir diretamente com a API do Discord 
para criar bots capazes de responder comandos, gerenciar servidores e automatizar tarefas.
</p>

<h2>📂 Estrutura do Projeto</h2>

<pre>
Nyx/
│
├── commands/        # Comandos do bot

│

</pre>

<hr>

<h2>⚙️ Como executar o bot</h2>

<h3>1️⃣ Clonar o repositório</h3>

<pre>
git clone https://github.com/AbnerSantosAlves/Nyx.git
</pre>

<h3>2️⃣ Entrar na pasta do projeto</h3>

<pre>
cd Nyx
</pre>

<h3>3️⃣ Instalar dependências</h3>

<pre>
pip install -r requirements.txt
</pre>

<h3>4️⃣ Configurar o token do bot</h3>

<p>
Crie um arquivo <strong>.env</strong> ou configure no arquivo de configuração:
</p>

<pre>
DISCORD_TOKEN=seu_token_aqui
</pre>

<h3>5️⃣ Executar o bot</h3>

<pre>
python main.py
</pre>

<hr>

<h2>📌 Como adicionar o bot ao Discord</h2>

<ol>
<li>Acesse o <strong>Discord Developer Portal</strong></li>
<li>Crie uma aplicação</li>
<li>Adicione um bot</li>
<li>Copie o token</li>
<li>Use o link de convite para adicionar ao servidor</li>
</ol>
